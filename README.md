# SEO Reverse Engineer — Website

Marketing site for the **SEO Reverse Engineer** Chrome extension. Built with Nuxt 4, dark theme only.

## Pages

- `/` — Landing
- `/features` — Product features from the extension
- `/privacy` — Privacy Policy
- `/terms` — Terms of Service

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm run preview
```

Or generate a static site:

```bash
npm run generate
```
